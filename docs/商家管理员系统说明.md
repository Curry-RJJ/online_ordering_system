# 商家管理员系统使用说明

## 功能概述

本系统新增了商家管理员功能，允许普通用户申请成为商家管理员，管理特定商家及其菜品。

## 角色说明

### 1. 普通用户 (user)
- 可以浏览商家和菜品
- 可以下单购买
- 可以申请成为管理员或商家管理员

### 2. 商家管理员 (merchant)
- 可以申请管理现有商家或创建新商家
- 可以管理自己所属商家的信息（需要管理员审核）
- 可以添加、修改、删除自己商家的菜品（需要管理员审核）
- 每个商家管理员只能管理一个商家

### 3. 管理员 (admin)
- 拥有所有权限
- 审核商家管理员申请
- 审核商家和菜品的修改请求
- 可以直接修改所有商家和菜品

## 使用流程

### 普通用户申请成为商家管理员

1. 登录系统
2. 进入"个人资料"页面
3. 点击"申请成为管理员"
4. 选择"申请商家管理员"
5. 填写申请理由并提交
6. 等待管理员审核

### 商家管理员申请管理商家

商家管理员有两种方式获得商家管理权：

#### 方式1：申请管理现有商家

1. 进入"个人资料"页面
2. 点击"申请管理商家"
3. 选择"申请管理现有商家"
4. 从下拉列表中选择要管理的商家
5. 填写申请理由并提交
6. 等待管理员审核
7. 审核通过后，该商家会关联到你的账号

#### 方式2：创建新商家

1. 进入"个人资料"页面
2. 点击"申请管理商家"
3. 选择"创建新商家"
4. 填写商家信息（名称、简介、地址、电话、菜系类型等）
5. 填写申请理由并提交
6. 系统会创建一个下线状态的商家
7. 等待管理员审核
8. 如果审核通过：
   - 商家会关联到你的账号
   - 商家保持下线状态，不会显示在主页
   - 你可以添加菜品并申请上线
9. 如果审核拒绝：
   - 创建的商家会被删除
   - 申请记录会保留

### 商家管理员管理商家

1. 获得商家管理权后，进入"商家管理面板"
2. 可以查看商家信息和菜品列表
3. 点击"修改商家信息"提交修改申请
4. 修改会在管理员审核通过后生效

### 商家管理员管理菜品

#### 添加菜品

1. 进入"商家管理面板"
2. 点击"添加菜品"
3. 填写菜品信息（名称、价格、描述、分类等）
4. 填写修改理由
5. 提交申请
6. 等待管理员审核
7. 审核通过后菜品会上架

#### 修改菜品

1. 在商家管理面板的菜品列表中找到要修改的菜品
2. 点击"编辑"
3. 修改菜品信息
4. 填写修改理由
5. 提交申请
6. 等待管理员审核
7. 审核通过后修改生效

#### 删除菜品

1. 在商家管理面板的菜品列表中找到要删除的菜品
2. 点击"删除"
3. 确认删除
4. 系统会提交删除申请
5. 等待管理员审核
6. 审核通过后菜品会被删除

**注意：** 
- 如果菜品在购物车中或有订单记录，无法删除，建议使用下架功能

### 管理员审核流程

#### 审核管理员申请

1. 登录管理员账号
2. 进入"审核申请"页面
3. 查看待审核的申请列表
4. 对于管理员申请：
   - 点击"通过"将用户设置为管理员角色
   - 点击"拒绝"拒绝申请
5. 对于商家管理员申请：
   - 点击"通过"将用户设置为商家管理员角色
   - 点击"拒绝"拒绝申请

#### 审核商家申请

1. 进入"审核申请"页面
2. 查看"商家管理员申请"列表
3. 对于申请现有商家：
   - 点击"通过"将商家关联到该用户
4. 对于创建新商家：
   - 查看商家信息
   - 点击"通过"保留商家（下线状态）并关联到用户
   - 点击"拒绝"删除创建的商家

#### 审核商家修改请求

1. 进入"商家修改审核"页面
2. 查看待审核的修改请求列表
3. 每个请求显示：
   - 商家管理员信息
   - 修改类型（商家修改/添加菜品/修改菜品/删除菜品）
   - 修改内容详情
   - 修改理由
4. 点击"查看详情"查看具体修改内容
5. 点击"通过"应用修改
6. 点击"拒绝"拒绝修改

## 权限说明

### 商家管理员权限限制

1. **只能管理自己的商家**
   - 无法查看或修改其他商家
   - 无法修改商家上线状态（由管理员控制）

2. **所有操作需要审核**
   - 修改商家信息需要管理员审核
   - 添加/修改/删除菜品需要管理员审核
   - 审核通过后才会生效

3. **一对一关系**
   - 每个商家管理员只能管理一个商家
   - 每个商家可以有多个管理员

### 管理员权限

1. **直接操作权限**
   - 可以直接修改任何商家和菜品
   - 修改立即生效，无需审核

2. **审核权限**
   - 审核商家管理员申请
   - 审核商家申请
   - 审核商家和菜品修改请求

3. **完全控制权**
   - 可以删除用户、商家、菜品
   - 可以修改用户角色
   - 可以控制商家上下线状态

## 状态说明

### 申请状态

- **pending (待审核)**: 申请已提交，等待管理员审核
- **approved (已通过)**: 管理员已通过申请
- **rejected (已拒绝)**: 管理员已拒绝申请

### 商家状态

- **is_active**: 是否在主页显示
  - `True`: 已上线，显示在主页
  - `False`: 未上线，不显示在主页
- **status**: 营业状态
  - `open`: 营业中
  - `closed`: 已打烊
  - `busy`: 繁忙中

### 修改请求类型

- **restaurant_edit**: 修改商家信息
- **dish_add**: 添加菜品
- **dish_edit**: 修改菜品
- **dish_delete**: 删除菜品

## 数据库变更

### 新增表

1. **MerchantApplication**: 商家管理员申请商家表
   - 存储商家管理员的商家申请记录
   - 包含现有商家申请和新建商家申请

2. **RestaurantChangeRequest**: 商家和菜品修改审核请求表
   - 存储所有商家管理员的修改请求
   - 包含修改内容的JSON数据
   - 记录审核状态和审核人

### 修改字段

1. **User.restaurant_id**: 新增，关联到Restaurant表
2. **User.role**: 扩展长度到20，支持'merchant'角色
3. **Restaurant.is_active**: 新增，布尔值，控制是否显示
4. **AdminApplication.application_type**: 新增，区分管理员和商家管理员申请

## 运行迁移

在部署或更新系统后，需要运行数据库迁移：

```bash
python upgrade_merchant_system.py
```

这会自动创建新表和更新现有数据。

## 注意事项

1. **数据完整性**
   - 删除用户前需要先解除商家关联
   - 删除商家前需要先删除相关菜品和订单

2. **审核流程**
   - 所有商家管理员的操作都需要管理员审核
   - 管理员应该及时处理审核请求

3. **商家上线**
   - 新创建的商家默认下线状态
   - 需要管理员手动上线后才会显示在主页

4. **申请记录**
   - 所有申请记录都会保留
   - 用户可以在个人资料页面查看申请历史

## 常见问题

**Q: 商家管理员可以管理多个商家吗？**
A: 不可以，每个商家管理员只能管理一个商家。

**Q: 如何让新创建的商家显示在主页？**
A: 管理员需要在商家管理页面将商家的is_active状态设置为True。

**Q: 商家管理员的修改什么时候生效？**
A: 所有修改都需要管理员审核通过后才会生效。

**Q: 如果申请被拒绝了怎么办？**
A: 可以重新提交新的申请，建议完善申请理由。

**Q: 商家管理员可以删除自己的商家吗？**
A: 不可以，只有管理员才能删除商家。
