## 🔴 P0 — 上线前必须完成

### 一、服务器 & 网络

- [ ] 购买云服务器（推荐阿里云 / 腾讯云，2核4G，约 ¥60–100/月）
- [ ] 绑定域名，完成 DNS A 记录解析到服务器 IP
- [ ] 申请 SSL 证书（Let's Encrypt 免费，Certbot 自动续期）
- [x] 配置 Nginx 反向代理（配置文件已预写至 `nginx/nginx.conf`，服务器到后取消 docker-compose.yml 中的注释即可启用）：
  - `proxy_pass` 转发到 Gunicorn:5000 ✅
  - 强制 HTTP → HTTPS 跳转（301 重定向）✅
  - 配置静态文件直出（`/static/` 目录）✅
  - SSL/TLS 安全头、Gzip 压缩 ✅
- [ ] 云服务器安全组：**只对外开放 80 / 443 端口**，关闭 5000 / 3307 等内部端口

### 二、安全加固

- [x] 修改 `docker-compose.yml` 中所有弱密码：
  - MySQL 密码已改为读取 `.env` 变量，本地默认值仅限开发 ✅
  - Redis 已增加 `REDIS_PASSWORD` 环境变量支持，生产环境设置后自动启用 `requirepass` ✅
- [x] 创建生产环境 `.env` 模板（`.env.example` 已提交，服务器上 `cp .env.example .env` 后填写真实值）✅
- [x] 确认 `.env` 已加入 `.gitignore`，`.env.production` 也已加入忽略 ✅
- [ ] **BUG-09 CSRF 防护**：安装 `Flask-WTF`，为所有表单加 CSRF Token（需授权安装依赖后实施）
- [ ] 确认登录失败限流已启用（flask-limiter 生产环境使用 Redis 后端）

### 三、数据库

- [ ] 确认 `docker-compose.yml` MySQL 数据目录已挂载到宿主机 volume（重启容器不丢数据）
- [ ] 首次部署前确认数据库初始化脚本正常运行（`entrypoint.sh` 中 `db.create_all()`）

- [ ] 准备数据恢复演练方案（确认备份文件能正常还原）

## 最关键的三件事

> 如果资源有限，优先确保以下三项：

1. **Nginx + HTTPS** — 没有它，域名无法访问、用户数据裸传
2. **改掉弱密码 + 配好 .env** — 否则数据库可能被公网扫描攻击
3. **数据库定时备份** — 用户数据和订单数据是最不可替代的资产
